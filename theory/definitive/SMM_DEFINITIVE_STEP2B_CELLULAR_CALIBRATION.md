# SMM Definitive Reconstruction — Step 2B
## Cellular calibration protocol before any whole-brain fitting

**Status:** Canonical experimental/computational protocol  
**Purpose:** Freeze the neuron<->K+ coupling from cellular biophysics before using EEG  
**Dependency:** Step 2A (K+ -> QIF/MPR bridge)

---

# 1. Scientific question

Before building the whole-brain SMM, answer two quantitative questions independently of EEG:

1. How much does a physiological change in extracellular potassium shift the effective excitability parameter of an excitatory or inhibitory QIF population?
2. How much extracellular potassium is generated by a unit increase in neuronal firing rate?

These two maps define the bidirectional neuronal-ionic coupling.

---

# 2. Primary excitatory calibration model

Use the dynamic-ion Traub-Miles cortical pyramidal model studied by Contreras et al. (2021).

Reasons:

- mammalian cortical pyramidal cell;
- type-I excitability at physiological K+;
- explicit extracellular potassium dynamics;
- explicit Nernst potentials;
- Na/K pump;
- published bifurcation analysis;
- experimentally tested in mouse cortical pyramidal neurons;
- demonstrates a SNIC regime at lower extracellular K+ and a transition toward HOM/bistability at sufficiently elevated K+.

The SMM core uses only the physiological SNIC neighborhood.

---

# 3. Primary inhibitory calibration model

Use a type-I Wang-Buzsaki fast-spiking interneuron as the primary inhibitory calibration model.

The membrane current contains:

\[
I_K=g_K n^4(V-E_K)
\]

with

\[
E_K=\frac{RT}{F}\ln\frac{K_e}{K_i}.
\]

The K+-sensitivity of the inhibitory population is calibrated independently of the excitatory population.

No constraint such as

\[
\chi_E=\chi_I
\]

is imposed.

---

# 4. Reference physiological state

Define a reference extracellular potassium concentration \(K_{e0}\) in the normal cortical range.

The exact value is not chosen to improve EEG fit.

It is chosen from physiological literature and then subjected to sensitivity analysis.

For every calibration model, fix:

- \(K_{e0}\),
- intracellular K+,
- temperature,
- Na+ concentrations,
- pump isoform/kinetics,
- maximal conductances,
- cell-specific baseline parameters.

These values form a frozen cellular-calibration configuration.

---

# 5. Continuation of the firing threshold

For each cell class \(a\in\{E,I\}\), define the threshold current

\[
I_{\rm th}^{(a)}(K_e)
\]

as the current at which the resting solution loses stability into repetitive firing in the physiological type-I regime.

Use numerical continuation rather than brute-force threshold search whenever possible.

For a grid

\[
K_e\in[K_{\min},K_{\max}]
\]

within the physiological/SNIC region:

1. continue the resting fixed point;
2. locate the saddle-node;
3. verify that the onset corresponds to SNIC;
4. record
   \[
   I_{\rm SN}^{(a)}(K_e);
   \]
5. continue the relevant codimension-one curves to determine the boundary of the SNIC validity region.

The primary empirical map is

\[
\boxed{
I_{\rm SN}^{(a)}(K_e).
}
\]

---

# 6. Equivalent-current definition

Define

\[
\boxed{
\Delta I_{K}^{(a)}(K_e)
=
I_{\rm SN}^{(a)}(K_{e0})
-
I_{\rm SN}^{(a)}(K_e).
}
\]

Interpretation:

- positive \(\Delta I_K\): elevated K+ acts like additional depolarizing drive;
- negative \(\Delta I_K\): elevated K+ acts like reduced drive.

The sign is therefore an output of the conductance model, not imposed by the SMM.

---

# 7. Normal-form calibration

At each reference SNIC point, compute the saddle-node normal-form coefficients.

For

\[
\dot{\mathbf z}=\mathbf f(\mathbf z;I,K_e),
\]

with right/left zero eigenvectors \(q,p\),

\[
Jq=0,\qquad
p^\top J=0,\qquad
p^\top q=1,
\]

compute

\[
a
=
\frac12 p^\top D^2_{\mathbf z}\mathbf f[q,q],
\]

\[
b_I=p^\top\partial_I\mathbf f,
\]

\[
b_K=p^\top\partial_{\ln K_e}\mathbf f.
\]

The center-manifold dynamics is

\[
\dot x
=
a x^2+b_I\delta I+b_K\delta\ln K_e+\cdots.
\]

After QIF rescaling,

\[
\tau_q\dot u=u^2+\eta,
\]

the mapping coefficient \(\chi_a\) is fixed.

The numerical continuation map and the analytical normal-form derivative must agree locally.

This agreement is a validation test.

---

# 8. Frozen QIF mapping

The population-level mapping becomes

\[
\boxed{
\eta_a(K_e)
=
\eta_{a0}
+
\chi_{a1}\ln(K_e/K_{e0})
+
\chi_{a2}\left[\ln(K_e/K_{e0})\right]^2+\cdots
}
\]

The smallest polynomial order that passes the cellular calibration is used.

Preference order:

1. first-order log-Nernst mapping;
2. second-order correction only if required;
3. no arbitrary spline unless a mechanistic reason exists.

The coefficients are frozen before EEG analysis.

---

# 9. Validation of the QIF approximation

For each \(K_e\) in the allowed physiological range:

1. simulate the parent conductance model near threshold;
2. simulate its calibrated QIF reduction;
3. compare:
   - threshold current;
   - f-I curve close to threshold;
   - latency to first spike;
   - firing-rate scaling near onset;
   - local phase-response behavior if available.

Primary requirement:

\[
\text{QIF reduction error}
\ll
\text{physiological K+-induced effect}.
\]

If this condition fails, MPR cannot be used as the definitive neuronal substrate.

---

# 10. Explicit validity boundary

Contreras et al. show that sufficiently elevated extracellular potassium can change the firing-onset geometry from SNIC toward saddle-node-loop/HOM dynamics and bistability.

Therefore determine

\[
K_{\rm SNL}^{(a)}
\]

for each calibration model.

The core SMM validity domain is

\[
\boxed{
\mathcal D_a
=
\{K_e: \text{firing onset remains in the calibrated SNIC regime}\}.
}
\]

A whole-brain simulation leaving this domain is:

- flagged;
- excluded from normal core inference;
- never silently interpreted using QIF/MPR.

Pathological high-K+ dynamics are a separate future extension.

---

# 11. Potassium efflux per spike

For each parent conductance model, calculate the excess outward K+ charge associated with one spike:

\[
Q_{K,a}^{\rm sp}
=
\int_{t_1}^{t_2}
\left[
I_{K,a}^{\rm out}(t)
-
I_{K,a}^{\rm baseline}(t)
\right]dt.
\]

If several neuronal K+ currents are present, sum all relevant outward potassium currents.

Convert to molar amount:

\[
n_{K,a}^{\rm sp}
=
\frac{Q_{K,a}^{\rm sp}}{F}.
\]

Repeat across:

- near-threshold firing;
- moderate physiological firing;
- the physiological K+ range.

Test whether \(Q_K^{\rm sp}\) can be treated as constant.

If not, use

\[
Q_K^{\rm sp}(K_e,R)
\]

with the simplest validated dependence.

---

# 12. Population source term for extracellular K+

Let

- \(\rho_{A,a}\) = neuronal membrane area of population \(a\) per unit tissue volume;
- \(\phi_e\) = extracellular volume fraction;
- \(R_a\) = firing rate.

Then

\[
\boxed{
S_{K,a}(t)
=
\frac{\rho_{A,a}}{F\phi_e}
Q_{K,a}^{\rm sp}\,
R_a(t).
}
\]

For E and I populations:

\[
\boxed{
S_K
=
\Gamma_E R_E
+
\Gamma_I R_I
+
S_{K,\rm sub}.
}
\]

The coefficients

\[
\Gamma_E,\Gamma_I
\]

are cellular/tissue calibration outputs.

They are not fitted freely to EEG.

---

# 13. Subthreshold potassium flux

The firing-rate source term is an approximation.

The calibration must measure the size of non-spike K+ currents near the resting operating point.

If subthreshold flux is negligible relative to spike-driven flux, omit it.

If material, represent it using the mean membrane state:

\[
S_{K,\rm sub}
=
\Phi_E(V_E)
+
\Phi_I(V_I).
\]

This is attractive because MPR already provides the mean membrane potential \(V_a(t)\).

Thus the potassium source may ultimately use both exact population observables:

\[
\boxed{
S_K=S_K(R_E,V_E,R_I,V_I).
}
\]

---

# 14. Cellular calibration uncertainty

The cell-to-population bridge is not known exactly.

Uncertainty must be propagated rather than converted into free fitting freedom.

For each calibrated coefficient:

\[
\chi_E,\chi_I,\Gamma_E,\Gamma_I,\ldots
\]

store:

- point estimate;
- physiological range;
- sensitivity to conductance parameters;
- sensitivity to \(K_{e0}\);
- sensitivity to temperature;
- between-model uncertainty.

These become informative priors or fixed uncertainty ranges in whole-brain inference.

They do not become unconstrained subject-level parameters.

---

# 15. Required robustness models

The primary E/I models are not sufficient by themselves.

Minimum robustness set:

## Excitatory
- primary: dynamic-ion Traub-Miles;
- secondary: another published cortical type-I conductance model.

## Inhibitory
- primary: Wang-Buzsaki type-I;
- secondary: another fast-spiking type-I model if available.

The central quantity is not agreement of all microscopic details.

It is robustness of the reduced maps:

\[
K_e\mapsto I_{\rm SN}
\]

and

\[
R\mapsto S_K.
\]

---

# 16. Pre-EEG acceptance criteria

The neuronal-potassium bridge is accepted only if all of the following pass:

### A. Bifurcation reproduction
The implementation reproduces published qualitative bifurcation structure of the parent model.

### B. Threshold continuation
\(I_{\rm SN}(K_e)\) is numerically stable and reproducible.

### C. Local theory
The center-manifold derivative agrees with numerical finite-difference continuation.

### D. QIF fidelity
The calibrated QIF reproduces near-threshold firing behavior throughout the physiological K+ range.

### E. Flux conservation
Integrated potassium currents and concentration source terms have consistent physical units and signs.

### F. Robustness
The qualitative K+->excitability mapping is not an artifact of one conductance model.

### G. No EEG contamination
None of the cellular mapping coefficients has been selected using EEG performance.

---

# 17. Consequence for the definitive SMM

If this protocol passes, the core whole-brain model has a closed, non-arbitrary mechanistic loop:

\[
\boxed{
(R_E,V_E,R_I,V_I)
\rightarrow
S_K
\rightarrow
K_e
\rightarrow
\text{astrocytic buffering}
\rightarrow
K_e
\rightarrow
(\eta_E,\eta_I)
\rightarrow
(R_E,V_E,R_I,V_I).
}
\]

The astroglial subsystem then controls the operating point and stability geometry of the neuronal network through a conserved ionic variable.

This is the technical realization of the published glial control-field hypothesis.

---

# 18. Failure conditions

The reconstruction must be abandoned or revised if:

1. physiological K+ changes produce negligible QIF-parameter shifts after realistic calibration;
2. QIF fails to approximate the parent conductance models over the required range;
3. the inferred whole-brain model requires K+ excursions outside the calibrated physiological domain;
4. EEG fits require glia->neuron coupling substantially larger than cellular physiology permits;
5. a generic slow field reproduces all SMM effects without the ionic constraints adding predictive value.

These are genuine falsification criteria, not rhetorical caveats.
