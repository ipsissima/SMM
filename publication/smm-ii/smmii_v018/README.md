# SMM-II v0.18 — resistance-calibrated 3D paired-recording assay

This directory supersedes the v0.17 paired-recording interpretation. It does not supersede the native migration ablation, the two-sided reach theorem or the reach–occupancy–retention proof. All graph ensembles are simulated, not measurements of CA1 topology. See REVISION_AUDIT_v018.md and PILOT_PROTOCOL_v018.md. The large electrical assay is not a full-size EDNM simulation.

## Reproduce
Python 3.13, NumPy 2.3.5, SciPy 1.17.0, Matplotlib 3.10.8; inherited code also uses openpyxl, NetworkX and SymPy. Start with `python validate_large.py`. Use serial batches (checkpoint files are optional intermediates, not part of the public archive); to replay each design use, e.g., `python batch_direct.py 31 64 0 1 clamped` followed by `python collect_checkpoints.py 31 64 1 clamped`. The other designs are `31 32 0 1 differential 11 21`, `31 32 0 0.5 clamped`, `15 32 0 1 differential`, and `15 32 0 0.5 clamped` (omit the start argument 0 for collect_checkpoints.py). The 15^3 runs used equivalent Fourier-preconditioned CG for clamped ECS; expect floating point differences below numerical tolerance. Each design uses the same predeclared seeds and age set. `python summarize_large.py` regenerates all readouts and planning estimates; `python make_figures.py` regenerates the two new figures with the sibling v017 migration result. `python revise_v018.py` regenerates the manuscript from the author-facing v017 source when available; build twice with pdflatex. The public computational ZIP excludes historical manuscript drafts and the original workbook; the author source ZIP contains the TeX dependencies and final manuscript. 

## Data provenance
`ca1_reference.csv`: pinned SMM-II age calibration and archived native response contrasts, not fresh biological data. `zhong_table3_verified.csv`: attributed source group summaries from Zhong et al. 2023 Table 3 B6:H21, DOI 10.1002/glia.24327; SHA256 of original workbook 22d3384db0f754b50052469c51ef2b1fc0a2942055fdd58f923afef01a5b1671. Original workbook not redistributed. Obtain it from the publisher and run sibling v017 `verify_zhong.py` against v016/v015_calibration_results.json. The extraction checks means and counts; figures 5e2 and 8 supply other published group anchors. `large_summary.csv` and `large_power.csv` retain adverse cases, including signed differences below zero. Raw graph-age matrices and dye proxies are in the five declared large result JSON files.
